# quanttide-bylaw-of-project-management

量潮项目管理章程 — 领域的根本规则与治理约定。

## 文档体系

| 文档 | 说明 |
|---|---|
| [index.md](index.md) | 主章程：领域定义、stage 建模、高质量标准 |
| [stage/initiation.md](stage/initiation.md) | 立项章程 |
| [stage/delivery.md](stage/delivery.md) | 交付章程 |
| [stage/retrospective.md](stage/retrospective.md) | 复盘章程 V1.0 |

**stage/** 是项目生命周期的工作空间——项目管理建模为立项 → 交付 → 复盘三个阶段，各阶段专项章程在此定义与持续维护。

**文档体系分工**：章程规定"必须怎样"（本仓库）；手册规定"具体怎样做"（[docs/handbook](https://github.com/quanttide/quanttide-handbook-of-project-management)）；案例回答"为什么"（[docs/gallery](https://github.com/quanttide/quanttide-gallery-of-project-management)）。案例教训经复盘升格为章程条款——代谢关系见主章程第五条。
